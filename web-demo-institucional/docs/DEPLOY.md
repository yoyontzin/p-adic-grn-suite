# Despliegue básico

## Backend

```bash
cd software-suite/web-demo-institucional/backend
python3 app.py
```

## Frontend estático

Servir `frontend/index.html` con cualquier servidor estático institucional.

## Componentes del despliegue

1. API backend para verificación (`/health`).
2. Interfaz frontend estática para demostración.
3. Integración con módulos de cálculo y reportes de la suite.
