# padic-grn-viz: Visualización y reportes de análisis p-ádico

## Resumen

Paquete de visualización y reportes para resultados producidos por `padic-grn-core` y `padic-grn-search`.

## Introducción

`padic-grn-viz` facilita la lectura de resultados con salidas gráficas reproducibles. Su objetivo es hacer más amigable la interpretación de métricas p-ádicas para usuarios técnicos y no técnicos.

## Comandos

- `pgviz-dependency-graph`
- `pgviz-hierarchical-graph`

## Alcance operativo

La versión actual implementa motores nativos para:

- gráfica de barras de `mu_E`, `mu_A`, `mu_I`,
- gráfica de posiciones del ordering.

Incluye plantillas visuales para reporte institucional.
