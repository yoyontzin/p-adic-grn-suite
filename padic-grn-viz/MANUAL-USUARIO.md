# Manual de usuario — padic-grn-viz

## Instalación

```bash
cd software-suite/padic-grn-viz
pip install -e .
```

## Comandos

### Dependencias

```bash
pgviz-dependency-graph
```

### Jerárquico

```bash
pgviz-hierarchical-graph
```

## Recomendaciones

- ejecutar desde entorno con `matplotlib` y `networkx` instalados.
- guardar resultados visuales junto con metadatos de corrida.
